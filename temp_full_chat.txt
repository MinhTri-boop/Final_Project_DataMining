Bạn hãy copy dán (chuột phải) từng dòng lệnh SQL dưới đây vào. Chú ý: **Bắt buộc phải có dấu chấm phẩy (;) ở cuối mỗi dòng lệnh**.

**Lệnh tạo Database:**
```sql
CREATE DATABASE gtd_dw;
```
*(Hệ thống sẽ hiện chữ `CREATE DATABASE` báo hiệu thành công).*

**Lệnh đổi mật khẩu cho tài khoản `postgres`:**
Bạn hãy thay chữ `NhapMatKhauCuaBanVaoDay` thành mật khẩu thực tế mà bạn muốn đặt (Ví dụ cái pass `Tri1003...` lúc nãy của bạn, và nhớ giữ lại 2 dấu nháy đơn `'` bao quanh mật khẩu nhé).

*(Hệ thống sẽ hiện chữ `ALTER ROLE` báo hiệu thành công).*

### Giai đoạn 1: Xuất dữ liệu (Export) từ máy tính của bạn
Nếu bạn đang dùng phần mềm **pgAdmin 4** để quản lý Postgres trên máy tính, hãy làm theo các bước click chuột sau:
1. Mở pgAdmin 4, mở mục Databases, click chuột phải vào Database `gtd_dw` (của máy bạn) ➔ Chọn **Backup...** (Sao lưu).
2. Ở tab **General**:
   - **Filename:** Bấm vào nút dấu 3 chấm `...`, duyệt đến màn hình Desktop và đặt tên là `gtd_backup.sql` (bắt buộc phải gõ chữ `.sql` ở cuối).
   - **Format:** Bấm xổ xuống chọn **Plain**.
3. Ở tab **Dump options**: Cuộn xuống mục *Type of objects*, đảm bảo đang để mặc định (không tích gì hoặc tích All).
4. Bấm nút **Backup** và chờ một lát để nó xuất toàn bộ dữ liệu ra màn hình Desktop của bạn.

*(Nếu bạn không dùng pgAdmin mà quen dùng dòng lệnh trên Windows, hãy mở Cmd và gõ: `pg_dump -U postgres -d gtd_dw -F p -f C:\Users\Acer\Desktop\gtd_backup.sql`)*

### Giai đoạn 2: Bắn file `.sql` lên máy ảo (Upload)
Vì máy `vm-core-backend` bị giấu kín trong Private Subnet, bạn phải "chuyền tay" file này qua 2 chặng.
Mở Windows Terminal / PowerShell (nơi bạn để file chìa khóa) và gõ lệnh sau:

**Chặng 1: Bắn từ Windows lên máy Bastion**
```bash
scp -i vm-bastion-key.pem C:\Users\Acer\Desktop\gtd_backup.sql azureuser@<IP-Public-Của-Bastion>:
```
*(Lưu ý: Bắt buộc phải có dấu hai chấm `:` ở cuối cùng dòng lệnh).*

**Chặng 2: Bắn từ Bastion vào Core Backend**
Bạn SSH vào máy Bastion (`ssh -i vm-bastion-key.pem azureuser@<IP-Public-Của-Bastion>`), rồi từ bên trong Bastion gõ lệnh truyền file đi tiếp:
```bash
scp -i core-key.pem gtd_backup.sql azureuser@<IP-Private-Của-Core-Backend>:
```

### Giai đoạn 3: Đổ dữ liệu vào Database (Import)
Lúc này file `.sql` đã nằm an toàn bên trong máy **Core Backend**. 
1. Từ máy Bastion, bạn SSH vào máy Core Backend:
   ```bash
   ssh -i core-key.pem azureuser@<IP-Private-Của-Core-Backend>
   ```
2. Sau khi đã vào tới nơi, bạn gõ lệnh sau để "Bơm" dữ liệu từ file sql vào Database trống mà bạn vừa setup ở Bước 3:
   ```bash
   psql -U postgres -d gtd_dw -f gtd_backup.sql
   ```
3. Hệ thống sẽ yêu cầu mật khẩu, bạn hãy gõ cái mật khẩu Database mà bạn đã setup lúc nãy ở Bước 3. (Lúc gõ pass, màn hình Linux sẽ không hiện ra dấu sao `***` hay bất cứ ký tự gì để bảo mật, bạn cứ gõ đúng rồi Enter là được).

Sau khi chạy xong, màn hình sẽ chạy chữ loằng ngoằng hiện `CREATE TABLE`, `INSERT`, `ALTER`... Khi nó dừng lại, xin chúc mừng, bạn đã có nguyên cái kho dữ liệu xịn sò trên Cloud! Tiếp theo chỉ việc Deploy Java và Python (Bước 4 & 5 lúc nãy) là hệ thống vận hành hoàn hảo.
